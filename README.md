Este proyecto es un proyecto "personal" que crea una necesidad ficticia acerca de una veterinaria de Animales (especialmente gatos, pero puede modificarse a variedad de animales).


Division de proyecto:
El proyecto esta dividido en 3 partes importantes
1- Home : Es la portada de la "veterinaria" cuyo proposito es dar información acerca de los veterinarios, direccion y accesibilidades
2- FormCats : Permite inscribir a un gato con informacion detallada e importante como : edad, raza, nombre, estado actual (sano, vulnerable, enfermo).
3- ListCat : Es el apartado que nos permite ver los gatos inscritos con su información a detalle, este componente sera mejorado en el futuro.

TENER EN CUENTA:
Este proyecto no posee backend, asi que se utiliza indexedDB para el almacenamiento de datos (via local);
Este proyecto es personal, no busca trabajar con empresas por inexperiencia de desarrollo empresarial, se desarrolla esto con fines educativos y adquisicion de experiencia personal en desarrollo.
El contenido como imagenes y fondos visuales estan hechos con inteligencia artificial.

Se espera seguir con el desarrollo y mejorarlo aun mas, aunque sea un proyecto basico, tiene un proposito noble.
